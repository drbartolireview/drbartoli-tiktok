Finalidad

Esta aplicación permite organizar y publicar vídeos autorizados en la cuenta de TikTok @drbartoli_oficial mediante la API oficial de TikTok.

Datos tratados

La aplicación puede tratar el identificador de TikTok, el nombre visible de la cuenta, tokens de autorización, información técnica de las publicaciones, textos, hashtags y vídeos seleccionados para publicar.

Uso de los datos

Los datos se utilizan únicamente para autenticar la cuenta, programar publicaciones, comprobar su estado y registrar errores técnicos. No vendemos ni cedemos datos personales a terceros.

Conservación y eliminación

Los datos se conservan mientras sean necesarios para el funcionamiento del automatizador. Puedes solicitar su eliminación escribiendo a [TU CORREO]. También puedes revocar el acceso desde la configuración de TikTok.

Seguridad

Las credenciales y tokens se almacenan mediante variables de entorno y no se publican en el código ni en los registros.
